# Product Catalog

## Overview

Product Catalog is a full-stack web application developed to manage and display product information through a user-friendly interface. The application allows users to browse products while providing backend support for handling product data and related operations.

## Features

* Display product listings
* Responsive user interface
* Client-server architecture
* Product data management
* REST API integration
* Dynamic content rendering

## Installation

### Clone Repository

```bash
git clone https://github.com/Kanishka0559/PRODUCT-CATALOG.git
```

### Install Dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### Run Application

Frontend:

```bash
npm start
```

Backend:

```bash
node server.js
```
